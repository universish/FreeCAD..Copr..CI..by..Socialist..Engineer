Automated continuous integration pipeline to repackage upstream OpenClaw prebuilt .deb and .AppImage releases into native RPM packages for Fedora Linux, built and hosted on Fedora Copr.

Overview
OpenClaw is an all-in-one personal AI assistant and communication gateway. Upstream distributes its primary CLI via npm (which strictly enforces Node.js 24.16+/26.1+ LTS runtime gates and WAL-safe SQLite capabilities) and occasionally publishes pre-compiled Linux desktop artifacts as standalone .deb and .AppImage packages (OpenClaw-<yyyy.mm.dd>-amd64).

Building Node.js/Electron desktop applications directly from source inside isolated build environments like Fedora Mock or Copr is frequently hindered by offline network boundaries, Node.js version constraints, and complex pnpm workspace toolchains. This repository resolves that issue by implementing an automated deb/AppImage-to-RPM repackaging pipeline:

Monitors upstream GitHub releases for prebuilt Linux distribution artifacts.

Smart Package Selection: Prioritizes .deb packages when available due to cleaner filesystem payload extraction; seamlessly falls back to unpacking .AppImage bundles (without requiring FUSE).

Bypasses source-only and npm-only tags to keep this repository strictly focused on binary repackaging rather than source compilation.

Sanitizes and normalizes payloads into a standardized architecture-specific source tarball (openclaw-<VERSION>-x86_64.tar.gz).

Generates a clean Source RPM (.src.rpm).

Dispatches automated build tasks to the universish/OpenClaw.. Copr repository across active Fedora chroots.

Repository Structure

.
├── .github/
│   └── workflows/
│       └── copr-ci.yml        # Automated release detector, extractor, and Copr trigger
├── openclaw.spec              # RPM packaging specification
├── latest-version.txt         # State tracker for the last processed upstream release
└── README.md

omponent Deep Dive
1. GitHub Actions Workflow (.github/workflows/copr-ci.yml)
The workflow runs on a scheduled cron trigger (every 6 hours) and supports manual triggering (workflow_dispatch) with an optional force_version input.

Operational Sequence:
Upstream Release Resolution: Queries the GitHub REST API for openclaw/openclaw releases, strips any leading v prefixes, and determines the latest release tag (e.g., 2026.9.5).

Prioritized Asset Detection:

Primary Target (.deb): Searches for assets matching OpenClaw-.*-amd64\.deb. If found, selects this path as the preferred repackaging format.

Fallback Target (.AppImage): If no .deb is published, searches for OpenClaw-.*-amd64\.AppImage.

Source/NPM Bypass: If neither prebuilt format exists, the workflow gracefully skips the run, ensuring no broken compilations are attempted.

Payload Extraction & Normalization:

For .deb: Unpacks using ar and extracts the underlying data.tar.* archive directly.

For .AppImage: Extracts the squashfs layer directly using 7z / unsquashfs, eliminating runtime FUSE dependencies inside GitHub Actions runner containers.

Identifies and standardizes application payloads into /opt/openclaw, alongside .desktop launcher shortcuts and high-resolution icons.

Isolated SRPM Generation: Compresses sanitized payloads into openclaw-<VERSION>-x86_64.tar.gz and runs rpmbuild -bs using openclaw.spec to output a clean, verifiable .src.rpm.

Copr Dispatch (copr-cli): Injects credentials from the COPR_CONFIG secret into ~/.config/copr and triggers non-blocking builds (copr-cli build --nowait) targeting the universish/OpenClaw.. project chroots (e.g., fedora-41-x86_64, fedora-42-x86_64, fedora-rawhide-x86_64).

Installation Instructions (Client-Side)
To install OpenClaw on Fedora using the Copr repository:

For Fedora (44, 45, Rawhide):

sudo dnf install -y vikunja-webui-pwa
For openSUSE (Tumbleweed & Leap 16.0):

sudo zypper install -y vikunja-webui-pwa
Update To bypass local metadata caching and upgrade the PWA launcher:
For Fedora:

sudo dnf upgrade --refresh -y vikunja-webui-pwa
For openSUSE:

sudo zypper refresh -f && sudo zypper update -y vikunja-webui-pwa
Removal If you want to uninstall the PWA launcher from your system:
For Fedora:

sudo dnf remove -y vikunja-webui-pwa
For openSUSE:

sudo zypper remove -y vikunja-webui-pwa
Uninstalling Software (Uninstall Packages)
sudo dnf remove -y vikunja vikunja-desktop veans
Disabling and Removing the Repository
# To temporarily disable the repository:
sudo dnf copr disable universish/Vikunja..

# To completely remove the repository from the system:
sudo dnf copr remove universish/Vikunja..
2. openSUSE (Tumbleweed & Leap 16.0) Commands
Adding the Repository (Add Repository)
For openSUSE Tumbleweed (x86_64 & aarch64):

sudo zypper addrepo -f https://copr.fedorainfracloud.org/coprs/universish/Vikunja../repo/opensuse-tumbleweed/universish-Vikunja..-opensuse-tumbleweed.repo
sudo zypper --gpg-auto-import-keys refresh
For openSUSE Leap 16.0 (x86_64 & aarch64):

sudo zypper --gpg-auto-import-keys refresh
Installing Software (Install Packages)
# To install all packages:
sudo zypper install -y vikunja vikunja-desktop veans

# To install only the desktop client:
sudo zypper install -y vikunja-desktop

# To install only the Vikunja server:
sudo zypper install -y vikunja

# To install only the Veans CLI tool:
sudo zypper install -y veans
Bypassing the Metadata Cache and Updating Packages
To bypass local metadata caching and immediately pull new builds or packaging revisions (vikunja-v<version>-<package-number>):

sudo zypper refresh -f && sudo zypper update -y vikunja vikunja-desktop veans
If package metadata does not resolve immediately:

sudo zypper clean --all && sudo zypper --gpg-auto-import-keys refresh -f
sudo zypper install -y vikunja vikunja-desktop veans
Uninstalling Packages
sudo zypper remove -y vikunja vikunja-desktop veans
Disabling and Removing the Repository
# To temporarily disable the repository:
sudo zypper modifyrepo -d copr:copr.fedorainfracloud.org:universish:Vikunja..

# To completely remove the repository from the system:
sudo zypper removerepo copr:copr.fedorainfracloud.org:universish:Vikunja..
